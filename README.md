# Website Project

Starter for landing pages and marketing sites.

## Structure

- `src/` - site source code
- `public/` - static public files
- `assets/` - source visuals, fonts, exports
- `docs/` - brief, sitemap, copy notes

## Start here

1. Fill `docs/site-brief.md`.
2. Add approved copy and assets.
3. Choose the stack and replace this README with project commands.

## Deployment

Recommended default: Netlify for static sites and landing pages.
